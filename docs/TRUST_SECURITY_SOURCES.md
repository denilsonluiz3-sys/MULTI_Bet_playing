# Fontes públicas do Trust & Security Engine

## Fonte regulatória principal

**Ministério da Fazenda / Secretaria de Prêmios e Apostas (SPA)**

Página: https://www.gov.br/fazenda/pt-br/composicao/orgaos/secretaria-de-premios-e-apostas/lista-de-empresas

A página pública informa empresa, CNPJ, marcas, domínios e portarias das empresas autorizadas. A própria SPA informa que a relação é atualizada periodicamente.

## Fonte regulatória complementar

A SPA mantém uma relação separada de agentes que operam por determinação judicial. Esse resultado deve ser apresentado como situação distinta de autorização administrativa comum.

Página: https://www.gov.br/fazenda/pt-br/internet/elias-testes-spa/empresas-autorizadas-1/processos-administrativos

## Proteção de dados

O tratamento de dados do aplicativo deve observar finalidade, necessidade, transparência, segurança, prevenção, qualidade e responsabilização previstos na LGPD.

Fonte: https://www.gov.br/anpd/pt-br/centrais-de-conteudo/materiais-educativos-e-publicacoes/glossario-anpd

## Princípios de implementação

- Consultar fontes públicas somente quando solicitado pelo usuário.
- Guardar o mínimo necessário para o relatório local.
- Informar fonte e data da consulta.
- Não transformar cache em prova de autorização atual.
- Não consultar ou enviar credenciais bancárias.
- Não visitar automaticamente o domínio pesquisado para classificá-lo.
- Não usar IA para decidir legitimidade regulatória.
